# 隐藏广播与能源菜单入口设计

## 目标

隐藏后台侧边栏中的“广播管理”和“能源管理”一级菜单入口及其子菜单，同时保留对应 HTML 页面、页面脚本和直接 URL 访问能力。

## 方案

菜单由 `app/config/menu.js` 的 `window.APP_MENU` 配置驱动，侧边栏组件 `app/components/sidebar.js` 只负责遍历配置并渲染。因此仅移除 `broadcast` 和 `energy` 两个一级菜单对象，不修改页面文件、页面路由或业务脚本。

## 验证标准

- 侧边栏不显示“广播管理”及其子菜单。
- 侧边栏不显示“能源管理”及其子菜单。
- 广播和能源目录下的 HTML 文件仍存在。
- 其他菜单项渲染配置不变。
