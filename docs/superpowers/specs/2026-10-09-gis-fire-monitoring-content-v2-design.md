# GIS 一张图消防监控二次重构设计

## 范围

本设计优先于 `2026-10-09-gis-fire-monitoring-content-design.md` 中的同名模块和右侧布局。仅调整 `web/pages/gis/one-map.html` 消防监控 Tab 及 `web/assets/css/gis-one-map.css` 中 `#gisPanel2` 专用样式，中央 GIS 地图、消防设施台账和其他 GIS Tab 保持现状。

## 布局

保持左右各三个模块，按信息量分配高度：

| 左侧 | 右侧 |
| --- | --- |
| 消防设备运行统计 | 消防设备巡检 |
| 消防设施台账 | 消防设备巡检状态分析 |
| 分区消防保障状态 | 设备报警 |

删除右侧“消防设备运行异常”。低高度桌面视口下不隐藏模块，表格、分区卡片和报警列表在各自卡片内滚动。

## 消防设备运行统计

- 顶部只展示在线、离线、报警三项指标。
- 下方按设备类型展示水平堆叠条形图，设备类型包括感烟/感温探测器、手动报警按钮、消火栓/灭火器、防火门和应急照明。
- 每个条形使用青绿色表示在线、灰色表示离线、红色表示报警。
- 每行显示设备类型、设备总数及三种状态的数量，三种状态数之和必须等于该类型设备总数。
- 设备类型较多时，图表区域纵向滚动。

## 消防设施台账

保留现有位置和内容，继续展示设施、位置、数量、有效期以及到期提醒。

## 分区消防保障状态

- 每张卡片第一行显示完整的分区编号和名称，例如 `F0101 防火分区`。
- 卡片内展示待巡检、设备异常、应急事件、逾期巡检四项数量。
- 卡片只有白色和红色两种状态：
  - 逾期巡检数大于 0 时，使用浅红背景、红色边框和红色圆点。
  - 逾期巡检数等于 0 时，使用白色背景、中性边框和绿色圆点。
- 待巡检、设备异常或应急事件不单独改变卡片颜色。
- 保留两列布局，分区较多时在模块内纵向滚动。

## 消防设备巡检

- 标题由“消防巡检维保”改为“消防设备巡检”。
- 顶部展示七项统计：本月任务、待巡检、巡检中、验收中、已完成、已关闭、已逾期。
- 指标使用紧凑的七列统计区，已逾期使用红色强调，其余使用中性或业务状态色。
- 下方列表表头为任务、设备、计划执行、状态、逾期状态。
- “状态”显示待巡检、巡检中、验收中、已完成或已关闭；“逾期状态”只显示正常或已逾期。
- 列表按已逾期、待巡检、巡检中、验收中、已完成、已关闭排序。

## 消防设备巡检状态分析

- 标题右侧提供今日、本月、本年切换，默认选中今日。
- 横轴按防火分区展示，切换时间范围时更新各分区的当期统计。
- 左侧数量轴对应待巡检、巡检中、验收中、已完成、已关闭五个柱形系列。
- 右侧百分比轴对应完成率折线，范围为 0%-100%。
- 完成率计算公式为：`已完成 / (任务总数 - 已关闭) * 100%`。
- 当分母为 0 时，完成率显示 `—`，不绘制该分区的折线数据点。
- 鼠标 hover 柱形或折线点时，显示当前分区名称、五个任务数及完成率的浮层小卡片。
- 切换时只重绘当前分析卡片，不刷新地图和其他模块。
- 原型使用页面内的今日、本月、本年演示数组，使用原生 SVG 绘制坐标轴、柱形、折线、数据点和图例。

## 设备报警

- 严格复用环境监控“设备报警”的卡片高度、标题高度、内边距、三项统计区高度、统计区与列表的间距、列表行高和滚动条样式。
- 保留报警总数、未处理、已处理三项统计和分级报警列表。
- 三项统计与下方报警列表之间保留与环境监控一致的 7px 间距。

## 空状态和错误边界

- 无巡检任务时，统计显示 0，列表区显示“暂无巡检任务”。
- 无报警时，三项统计显示 0，列表区显示“暂无设备报警”。
- 分析数据不可用时，保留卡片高度和时间切换，图表区显示空状态，不使用虚假零值柱代替。

## 验证

- 确认左右各三个模块与布局顺序一致，右侧不再出现“消防设备运行异常”。
- 确认运行统计只使用在线、离线、报警三种口径，每个设备类型的数量能对齐总数。
- 确认分区卡片只有白色和红色两种状态，并且仅逾期巡检能触发红色状态。
- 验证巡检表的七项统计和五个表头。
- 验证今日、本月、本年切换后柱形、折线和 hover 小卡片同步更新。
- 对比环境监控与消防监控的设备报警，确认卡片高度、内部行高和统计/列表间距一致。
- 在 1920x1080 和 1366x768 视口下检查无模块重叠、无文字裁切，内部滚动、地图和分区联动正常。
