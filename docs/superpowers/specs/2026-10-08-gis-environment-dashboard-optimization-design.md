# GIS 环境监控页面优化设计

## 范围

仅优化 `web/pages/gis/gis-environment.html`。保留现有 GIS 地图、点位、图层控制、态势带和静态原型数据，不改变其它 GIS 子页或后台环境监测列表页。

## 布局

- 页面主体使用视口高度约束，桌面端默认一屏展示左侧三块和右侧三块内容。
- 现有卡片标题右侧的副标题、分区说明和标签全部移除，标题只保留模块名称。
- 地图位于中央列，左右看板高度跟随视口自适应。
- 左侧分区环境矩阵默认显示 4～5 条记录，其余记录保留在卡片内部滚动容器中。
- 右侧报警卡采用固定高度，默认可见最新两条报警，超过两条时仅报警列表区域滚动，不推动页面整体高度。
- 当视口较窄时保留响应式列布局，允许页面自然降级为纵向排列。

## 右侧模块

### 设备数量及状态统计

将设备总数、在线、离线、故障率等信息收敛为紧凑的横向指标组，压缩标题、内边距和数字区域高度。状态颜色保持蓝、青、灰、红的既有语义。

### 实时 / 历史运行监测

- 标题为“实时 / 历史运行监测”，右侧使用“今日 / 本月 / 本年”分段切换。
- 默认激活“今日”。
- 今日横坐标为 00:00～24:00；本月横坐标为 1～31 日；本年横坐标为 1～12 月。
- 纵轴上方显示“单位（％）”，不再显示“在线率”。
- 图表采用现有 SVG 方案，通过前端脚本切换横坐标文本和折线路径数据。
- 鼠标悬浮折线点或图表区域时，显示在线、离线、故障率三项指标。

### 设备报警

- 统计区展示报警总数、未处理、已处理三个指标，采用紧凑数字组。
- 报警列表固定高度，默认展示最新两条；超出部分使用内部纵向滚动。
- 报警条目保留等级色条、发生时间、设备位置和处理状态，不增加新的业务动作。

## 交互与数据

- 时间维度切换只更新右侧监测卡，不影响地图、左侧矩阵和其它卡片。
- hover 浮层根据当前维度显示对应数据点，并在鼠标离开后隐藏。
- 保持现有静态数据和原型事件，不引入第三方图表库。
- 页面高度和卡片高度使用 CSS 变量集中控制，便于后续继续调整。

## 验证

- 在桌面宽度下检查页面首次加载没有主体纵向滚动条。
- 检查左侧矩阵只显示 4～5 条并可在内部滚动查看其余数据。
- 检查右侧报警默认显示 2 条，超出后仅报警列表滚动。
- 分别点击“今日”“本月”“本年”，确认横坐标和图表数据随之更新。
- hover 图表时确认浮层同时显示在线、离线、故障率，纵轴单位显示为“％”。
- 在窄视口下确认卡片不会出现横向溢出。
