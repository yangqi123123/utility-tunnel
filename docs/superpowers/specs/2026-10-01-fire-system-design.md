# 消防系统综合列表设计规格

## 1. 背景与目标

在现有“视频监控”一级菜单下方新增“消防系统”一级菜单，提供一个统一的消防系统综合列表页。平台只展示第三方系统同步的设备状态、报警信息和运行参数，不提供控制、配置或写入第三方系统的能力。

本次覆盖六类消防子系统：

1. 火灾自动报警系统（FAS）
2. 防火门监控系统
3. 消防电源监控系统
4. 电气火灾监控系统
5. 应急照明与疏散指示系统
6. 感温光纤系统

页面还需要支持报警点附近视频的辅助决策入口，帮助值班人员复核报警。

## 2. 导航与页面边界

- 在 `视频监控` 一级菜单后新增 `消防系统` 一级菜单。
- 一级菜单使用消防相关线性图标，默认链接到新的综合页面 `web/pages/monitoring/fire-system.html`。
- 新页面的 `body` 使用 `data-menu-key="fire-system"`，沿用现有应用壳层、顶部工具栏、右侧抽屉和 TOB 设计令牌。
- 现有 `火灾报警系统` 页面和链接暂不删除，保持已有书签和内部链接可用；新页面不依赖旧页面的状态。

## 3. 页面信息架构

### 3.1 顶部摘要

展示四项只读指标：

- 第三方接入状态：正常、延迟或异常，并显示最近同步时间。
- 消防设备总数：六类系统的设备合计。
- 当前报警：未恢复的火警、故障或监管信号数量。
- 在线率：在线设备数 / 设备总数。

摘要数字由当前全部数据计算，不随列表筛选条件变化，避免误把筛选结果当成系统总况。

### 3.2 筛选工具栏

筛选项从左到右为：

- 系统类型：全部、六类子系统。
- 设备状态：全部、在线、预警、故障、离线。
- 报警等级：全部、紧急、重要、一般。
- 防火分区：全部和数据中的分区。
- 关键词：匹配设备名称、设备编码、位置和报警描述。
- 操作：搜索、重置、刷新数据。

筛选采用显式“搜索”触发；回车等同于搜索。重置后恢复全部条件并刷新列表。

### 3.3 综合列表

主列表用于密集扫描，固定展示以下字段：

| 字段 | 说明 |
| --- | --- |
| 系统类型 | 六类消防子系统之一 |
| 设备名称 / 编码 | 设备主名称及第三方编码 |
| 精确位置 | 防火分区、舱室、区段等定位信息 |
| 当前状态 | 在线、预警、故障、离线 |
| 运行参数 | 与系统类型相关的只读参数和单位 |
| 最近报警 | 最近一条报警的时间、类型或“无” |
| 更新时间 | 第三方最近同步时间 |
| 操作 | 查看详情；有未恢复报警时显示“附近视频” |

点击整行或“查看详情”打开右侧详情抽屉。表格支持横向滚动，桌面端保持可读列宽。

### 3.4 详情抽屉

右侧抽屉分为三段：

1. 设备摘要：名称、系统类型、状态、第三方编码。
2. 位置与运行参数：精确位置、参数名称、当前值、单位、采集时间。
3. 报警与同步记录：最近报警、恢复状态、数据来源、最近同步时间。

抽屉只提供关闭操作，不提供启停、复位、消音、阈值配置等写操作。对离线设备明确显示“暂无实时参数”。

### 3.5 辅助决策抽屉

报警行上的“附近视频”打开大尺寸右侧抽屉，展示：

- 报警点名称、系统类型、报警时间和防火分区。
- 附近摄像机列表，按距离排序，显示摄像机名称、位置、在线状态。
- 一个可识别为视频预览的只读画面区域；离线摄像机显示信号中断状态。
- “打开视频监控”入口，跳转现有实时视频页面并保留位置上下文。

该功能只做复核入口，不在消防页面内实现视频云台、录像控制或报警确认写入。

## 4. 数据模型与状态

每条设备记录至少包含：

```text
id, name, system, systemCode, deviceType, zone, location,
status, statusLabel, parameters[], latestAlarm, updatedAt, source
```

其中 `parameters[]` 为 `{ label, value, unit, trend? }`；`latestAlarm` 为 `{ type, level, message, time, restored }` 或 `null`。

状态映射：

- `online`：在线 / 正常，使用绿色。
- `warn`：预警，使用黄色。
- `fault`：故障，使用红色或红黄组合提示。
- `offline`：离线，使用中性灰色。

报警等级映射为紧急、重要、一般。颜色不是唯一信息，必须同时展示文字标签。

页面使用本地 mock 数据模拟第三方接入，数据字段和渲染结构按未来接口形状组织，便于后续替换为真实请求。

## 5. 数据流与交互

1. 页面加载时读取统一的本地消防设备数据集，计算顶部摘要并渲染列表。
2. 搜索、筛选只改变列表结果，不改变全量摘要指标。
3. 点击设备行根据设备 ID 查找记录，打开详情抽屉。
4. 点击“附近视频”根据设备位置查找 mock 摄像机，按距离排序并打开辅助决策抽屉。
5. 点击刷新更新时间和第三方接入状态，重新渲染当前筛选结果；不改变筛选条件。
6. 当数据为空时显示空表状态；刷新异常时保留当前列表并显示可重试的接入异常提示。

## 6. 视觉与响应式约束

- 采用现有 TOB 设计令牌：浅灰蓝页面背景、白色内容卡片、蓝色主色、低圆角、8px 间距基线。
- 页面主体为侧边栏 + 顶栏 + 内容区，不使用营销式 hero 或装饰性大卡片。
- 状态颜色沿用绿色、黄色、红色、灰色语义。
- 抽屉宽度遵循现有右侧抽屉规范，窄屏使用 `min(width, 90vw)`，表格保留横向滚动。
- 所有按钮和图标提供可识别文字或 aria-label；不依赖颜色区分状态。

## 7. 验证范围

- 菜单顺序、选中态和新页面路由正确。
- 六类系统筛选均能得到对应数据；状态、等级、分区和关键词组合筛选有效。
- 摘要指标与全量 mock 数据一致，筛选不会误改变摘要。
- 设备详情抽屉和附近视频抽屉能正确打开、关闭，离线状态和空数据状态可见。
- 刷新、重置、回车搜索以及页面窄屏布局可用。
- 不出现控制第三方消防设备的写操作入口。
