# GIS 一张图安防监控优化设计

## 目标

优化 GIS 一张图的安防监控标签页，使左右两侧模块聚焦视频、门禁、告警和关键区域监控，并复用现有通行记录页面与系统首页视频监控能力。

## 页面布局

安防监控标签页保持现有地图为中心、左右信息栏覆盖在地图两侧的整体结构。

左侧自上而下：

1. 视频设备概览：展示摄像机总数 433、枪式摄像机 132、半球摄像机 290、球型摄像机 11。
2. 门禁系统：上部展示设备总数、设备故障率、在线、离线；下部展示最近通行记录，字段包含人员、时间、通行方式、门禁设备、通行位置。

右侧自上而下：

1. 视频监控系统。
2. 系统告警记录。
3. 关键区域监控，复用系统首页现有视频监控画面和数据结构。

所有模块标题右侧的浅色说明文字删除。明确的操作按钮和状态操作不属于说明文字，可以保留。

## 通行记录弹窗

门禁系统标题栏右侧提供“通行记录”按钮。点击后打开大尺寸模态弹窗，使用 iframe 加载现有 `web/pages/monitoring/pedestrian-record.html?embedded=1` 页面。

弹窗支持关闭按钮、点击遮罩关闭和 Escape 关闭。弹窗内容区域应适应桌面视口，表格区域可滚动且不裁切主要操作。

## 嵌入模式

现有通行记录页面仅在 URL 参数 `embedded=1` 时进入嵌入模式：

- 隐藏左侧公共菜单。
- 隐藏顶部公共导航。
- 移除为公共框架预留的外边距和最小高度，使筛选区与表格适配 iframe。
- 保留筛选、重置、搜索、导出、查看、分页等原有业务功能。

未携带 `embedded=1` 时，通行记录页面的结构、导航和功能保持不变，避免影响“子系统 - 门禁系统”的既有使用方式。

## 实现边界

优先沿用 `one-map.html` 已有的标签页增强模式，仅针对 `gisPanel3` 注入安防模块内容和交互，不重写其他 GIS 标签页。样式补充到现有 `gis-one-map.css`，并复用已有颜色、卡片、按钮及视频模块设计语言。

不新增后端接口，不改变现有模拟数据存储，不调整门禁子系统路由。

## 验证

- 安防标签页左右模块顺序、标题和指标符合需求。
- 所有浅色标题副文案均已移除。
- 通行记录弹窗能够打开、关闭并完整显示嵌入页面。
- 嵌入页面筛选、重置、搜索、导出、查看和分页仍可使用。
- 直接打开通行记录页面时，公共菜单、顶部导航和原有功能保持不变。
- 常见桌面分辨率下无文字重叠、按钮裁切和不可达内容。
