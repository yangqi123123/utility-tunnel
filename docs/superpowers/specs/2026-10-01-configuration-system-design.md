# 组态系统设计规格

## 目标

在“网络管理平台”菜单下新增“组态系统”，提供一个单页双页签工作台，用于查看网关拓扑和设备拓扑，直观呈现网关、通信链路、报警位置及设备运行状态。

## 交互范围

- “网关拓扑”和“设备拓扑”通过同一页面的页签切换。
- 网关拓扑展示中心平台、区域网关、边缘网关及通信链路质量。
- 设备拓扑展示网关下挂设备、设备类别、设备运行状态和报警节点。
- 左侧提供区域、节点类型、运行状态、链路类型筛选和图层开关。
- 点击节点更新右侧详情面板，包含名称、编码、区域、上下游连接、实时状态和最近告警。
- 告警节点支持列表定位和画布聚焦；画布支持缩放、复位和节点高亮。

## 页面结构

新增 `web/pages/network/configuration.html`，复用公共侧边栏、头部和抽屉组件。页面采用当前后台的浅色壳层，核心拓扑区域使用深色网格画布、荧光链路和高对比状态色。

页面分为：

1. 页面标题与操作区：页签、刷新时间、复位和全屏操作。
2. 指标摘要：网关总数、在线率、链路数量、当前告警。
3. 组态工作区：左侧筛选，中部 SVG 拓扑画布，右侧节点详情和告警列表。
4. 底部状态表：按当前页签列出节点/设备状态、位置和最近更新时间。

## 数据与状态

页面使用内置演示数据，不新增后端接口。拓扑节点统一包含 `id`、`name`、`type`、`zone`、`status`、`links` 和 `alarm` 字段。状态包括 `online`、`warn`、`fault`、`offline`。筛选、页签和节点选择均由页面本地状态驱动，并实时更新摘要、画布和详情。

## 实现与验证

- 在 `app/config/menu.js` 中将“网络管理平台”扩展为带子菜单的菜单项，并加入“组态系统”链接。
- 使用 SVG 绘制拓扑连线和节点，避免引入新依赖。
- 复用 `window.openAppDrawer` 展示节点详情。
- 为关键交互添加轻量测试：菜单路由存在、页签切换、节点详情、状态筛选、告警定位。
- 在桌面宽度和窄屏宽度检查画布不溢出，筛选和详情区域保持可读。
